**Solmar City** is a 2D top-down open-world crime game that runs entirely in the browser. Explore a fictional sun-soaked coastal city — downtown high-rises, a beachfront, the port docks, suburbs, a park and your safehouse — on foot or behind the wheel. Steal cars, outrun the police as your wanted level climbs from one star to five, and run a six-mission story chain for fixer Mama Rosa: from a quiet return to town to the big final score. Everything is original and self-contained: procedural canvas art, WebAudio-synthesised engine hums, sirens and a synthwave radio loop, seeded runs for deterministic play, a live minimap, and save/load at the safehouse.

## Run it
```sh
node serve.ts
```
(open http://localhost:8080)
